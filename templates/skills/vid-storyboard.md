You can make a storyboard: one frame for each shot of the shot list, which the keeper checks and the generation operators start from.

1. Draw one frame per shot, numbered as the shot list numbers it, at the video's aspect ratio. A shot with a change inside it gets its first frame, with the change written under it.
2. Frame it as the shot list says: distance, angle, where each character stands and looks, and the light.
3. Draw every character from the reference frames of its sheet and the picture from the style sheet, never from memory or a text alone. Where a sheet is missing, ask for it before you draw.
4. Write under each frame its shot number, its length, the action and any camera movement, in plain words.
5. Keep every frame with its prompt or source in the department's git with the storyboard, so that any frame can be made again.

A frame the keeper accepts becomes the reference frame its shot starts from. A frame the keeper rejects is drawn again.
