Find the languages the assignment touches from the project files and declared toolchain. Use the repository's documented build, style, test and language checks within the assignment and company policy. Discover the installed tools from the current environment.

Run the project's configured checks locally for the changed work. Use run_tests for the checks of an assigned task. Reuse compatible prepared dependencies when verified; prepare missing inputs through the declared path. Report a missing or unsupported capability by purpose and say which checks actually ran.

Keep the repository record in its required language. Use the intended audience's language for user-facing text.
