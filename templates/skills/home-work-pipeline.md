When assigned to plan or assess checks for a family's home devices or household work, use its records, device metadata, assigned work and the notebook. Check each item where a mistake cannot be undone, risk adds up item by item, or code cannot check it. Batch the rest with the owner's sample. The department owner is the person named for this department, or the CEO when there is none. The employee assignment and task gates select the work route, not the selected abilities.

## Item by item

- Check changes to devices and scenes on each affected device, following the notebook. Keep a way to restore the previous setting. Irreversible deletion needs the CEO's yes, and a person makes payments and signs in the company's name. Streams and recordings need a separate assignment and existing access.

## In a batch

- Group routine checks and changes the notebook allows. Record what you did and any part that needs someone at the device.
- Lists of bills, supplies, chores and devices are gone through together when a list is due.

## By sample

- Compare a sample of the home's records, such as devices on the network, bills or supplies, with what the device, the statement or a person shows. A wrong entry means going through that whole list.

## By code

- Totals, next dates, price rises, double charges, unknown devices on the network and calendar clashes are computed, not estimated.
- Each code check has fast tests, including cases it must reject. A check named here that your tools do not run yet stays with a person, item by item, until they do.

## By a model

- A suggestion a model makes decides nothing here and has no example set yet: it reaches a person as a suggestion.
- A model check has a versioned set of examples with known answers, labelled by someone other than its author, and a threshold the department owner sets. Run the set when the check, its prompt, its lists or the provider model changes, not on every item, and count false accepts and false rejects apart. Every miss found in real work becomes a new example. Until a set has run for a check, that check proves nothing: say so and keep a person on what it would pass. Irreversible deletion needs the CEO's yes, whatever a set shows.

## Descriptions and measures

- For the records in scope, describe the network and devices or the supplies, bills and calendar: what they hold, who looks after them and where the checks above stand. Keep the description and all family information in the department notebook, private to the home. Read only the data the assignment needs, and never ask for or store card, bank or account secrets.
- Name the department's own measures, such as reminders in time and requests waiting for a person, in the department description: the head sets it with "change_department" (about) under the department's rules. The pipeline report of a turn says when a department has no description.
- Return the proposed check plan, action requests and missing evidence to the person who assigned this work. No check plan grants permission for physical actions or recording-content access.
