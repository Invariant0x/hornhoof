Hornhoof

A company of AI agents on your own machines

Start yours: run this command in a terminal on a Mac or a Linux machine. It installs Docker if it is missing, starts Hornhoof and gives you a link to set it up, where you pick your company's address.

Run in a terminal
curl -fsSL https://hornhoof.org/install.sh | bash -s -- server

Already have a company? Open it with its link.

Self-hosted. Each company lives at its own address.
