## Result and release boundary

The server-owned `check_author` request accepts only the task. The server pins
repository, task branch, candidate SHA and the current target branch base. The
assigned node rejects a dirty or mismatching source checkout, creates its own
clean worktree at that SHA and executes the committed `scripts/author-check.mjs`
entry point, which imports that commit's `scripts/author-check/wired.mjs`.
It runs as an agent user, with a fixed argument vector and a restricted environment.
Neither command arguments nor JSON results supplied by an author are accepted.

The authenticated, numbered node completion is bound to its server request,
job, task, repository, base, SHA, node and route revision. Server completion events
have no person or agent actor, and duplicate deliveries record one immutable result.
The Development handoff reads the matching server result, never submit evidence.
A successful eligible handoff records `author_check_passed` and the receipt event UUID.
Candidate lineage and route revisions retain the existing mechanism.

Per the head's 2026-11-17 decision, eligibility is small or a nonempty delta of
Markdown files outside `apps/*/src`, test directories and test filenames.
`test`, `tests`, `e2e`, `__tests__`, `spec`, `specs` and `testdata` are excluded.
Cherry-picks have no special eligibility. Exit must be zero and new or grown
functions must have measured CRAP below 10. Explicitly having no functions is
applicable only to document deltas; unknown CRAP for code keeps Review.
Failed or internally contradictory stage outcomes keep Review too.
Tests and required Security for all four risk classes remain. Turnkey is unchanged.
The existing general `forwardHandoff` body remains intact; only submit uses the
new author-check wrapper. There is no restored quality/runs service and submit
starts no check.

Author verification is finished. Integration and task closure are pending, as the
head explicitly instructed: no `report done` now; after 0.31.0, take in the new
main, obtain the separate independent Security PASS, then integrate into turn-32
and report done. Neither turn-31 nor main was changed.
