# Ancient Egypt pack: textures, water and plants, sources and licences

Every picture in the finished map is **made by us**. No image file comes from outside, and nothing comes from a
commercial game. They are generated by code in this repository and licensed like the repository (MIT). When artists
deliver hand-painted replacements, add their rows below with the source and licence of each file (free licences only:
CC0, CC-BY, CC-BY-SA, OFL, or made by us).

| Picture | Made by | Where | Licence |
|---|---|---|---|
| Ground textures: bank, grass, field, sand, dune, rock, quarry, silt (fertile soil), dust (road dust) | generated in code, seamless 512 x 512 texels that repeat every 4 x 4 tiles | `getMaterialTextureRgb` in `src/world/smooth-terrain-baker.ts`, materials listed in `pack.ts` | made by us, MIT |
| Water: ripples, highlights, shore foam | generated in code, animated as a separate layer under the ground | `buildLiquidSurfacePixels` in `src/world/smooth-terrain-baker.ts`, `liquidLayer` in `pack.ts` | made by us, MIT |
| Plants: date palm, papyrus, river reed, tamarisk bush, grass tuft, dry scrub, sandstone pebbles, sycamore fig | drawn in code from the palette of each kind, 3 to 4 variants each | `src/world/plant-sprites.ts`, kinds and palettes in `plants.ts` | made by us, MIT |

Plant kinds are only named after real plants for readability. No botanical drawing, photograph or game sprite was
copied or traced.

## Slots for artist work (declared, not loaded yet)

The manifest already names where artist files will go; the engine draws its own pictures until a later task loads them.

* A ground texture: `textureUrl` on its material in `pack.ts`: a seamless top-down 1024 x 1024 image.
* A plant: an `art` entry on its kind in `plants.ts`: `url` of the image, optional `windMaskUrl` (a grayscale image,
  how much each pixel moves, 0 rooted and 1 free) and the passport, which is the artist's `.json` next to the image
  (`root_point`, `crown_center`, `crown_hub`, `height`, `crown_width`, in image pixels, y down). `parsePlantPassport`
  in `src/world/plants.ts` reads that file.
